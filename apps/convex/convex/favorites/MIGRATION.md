Old savedViewFavorites readers/writers remain canonical. New generic view-target mutations are explicitly unavailable during the transition. Internal backfill copies their immutable view/user/workspace identity, original creation order, and source ID idempotently. Reconcile removes migrated rows whose source disappeared. Deploy additive schema/functions first, scan both hosts. Under a short old-writer freeze, rerun backfill and reconcile to completion and verify zero additional changes plus matching source/destination identities. After both hosts verify new owner reads/writes, remove old table and legacySourceId metadata via bounded cleanup, then remove obsolete migration entrypoints. Do not remove the source table while schema IDs still reference it. New per-user folder metadata is not used by old consumers before activation. No legacy route or sidebar has been cut over by this backend stage.
