# Preserved project form owner

Existing production consumers are `components/projects/create/root.tsx`, `project/create/common-attributes.tsx`, `projects/create/attributes.tsx` and `project/form.tsx`. They submit real name, identifier, description, network, logo, lead and timezone fields; dropping them to satisfy the old small native create mutation would lose user input.

`ProjectSerializer` validates name/identifier uniqueness and rejects `Project.FORBIDDEN_IDENTIFIER_CHARS_PATTERN`. The model permits name255 and identifier12; the actual form remains1–10 characters. Canonical native validation now preserves the API's12-character and non-Latin/digit domain instead of the prior ASCII letter-first2–10 restriction. Task-address resolution reuses that parser, with raw address whitespace rejected. Existing IDs and sequence numbers do not change. Names/identifiers of recoverable deleted native projects remain reserved, consistent with native lifecycle retention; legacy reservation-table deletion/import reconciliation remains separate.

`createProject` remains the only project writer. Optional description/timezone/lead inputs are validated before commit, stored atomically with branding/network and membership initialization. A non-creator lead receives project-admin membership through the canonical grant owner, matching legacy create. A workspace guest cannot be elevated to admin (intentional existing security invariant); invalid grants roll back the entire transaction. Lead changes in settings do not grant membership, matching the legacy PATCH path. Lead IDs must identify unrestricted active same-workspace accounts; the settings read redacts the label after workspace membership revocation.

`projects.form.get/save` owns the coherent whole-form snapshot: metadata revision plus existing timezone token, all fields and canonical lead label. It authorizes actual workspace/project admins. All metadata is validated before one atomic patch. Existing settings.save retains its current API but now shares name/identifier validation, so it cannot bypass uniqueness. Independent timezone.save remains a real existing caller; captured expectedTimezone prevents a whole-form edit from overwriting it even without metadata revision change. Missing optional leadId means no lead, not an incomplete backfill.

Current description limit remains the existing native20,000-character budget; legacy TextField capacity is broader. Rich project descriptions, default-assignee properties and exact REST request mapping remain separate parity work. Production forms are not switched and no route/deployment is activated by this source slice.

Current checkout verification: Convex TypeScript 7 and Oxlint pass. The previously drafted project test file was removed under the repository's sparse-test cleanup request; no project form behavior test or deployed-browser acceptance was run for this commit. The production form remains on Django.
